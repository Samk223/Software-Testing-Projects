Test Plan : E-commerce Website

1. Project Overview

Application: SauceDemo //https://www.saucedemo.com

Testing Type: Manual Testing
Project Type: Independent QA Portfolio Project

2. Objective
To verify that users can log in, browse products, manage their shopping cart, and complete the checkout process successfully.

3. Scope of Testing

- Login functionality
- Product listing
- Add to cart
- Remove from cart
- Cart quantity and product details
- Checkout form
- Order completion

4. Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Exploratory Testing
- Regression Testing

5. Test Environment
Application: https://www.saucedemo.com/
Browser: Google Chrome
Testing Method: Manual
Test Account: standard_user

6. Entry Criteria

- Application is accessible.
- Test credentials are available.

7. Exit Criteria

- Planned test cases have been executed.
- Actual results and statuses are recorded.
- Reproducible defects are documented.

8. Deliverables

- Test Plan
- Test Cases
- Test Execution Results
- Bug Reports (if defects are found)
- Evidence Screenshots
